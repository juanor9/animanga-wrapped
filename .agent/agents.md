# Confidential Environment Variables

- The `.env` file holds sensitive data (API keys, secrets, and `NEXT_PUBLIC_REACT_APP_BASE_URL`).
- **Never** expose its contents in documentation, comments, or generated files.
- When mentioning environment variables, describe their purpose without showing actual values.
- This file serves as a reminder for developers and AI agents that the `.env` file is private and must not be read or disclosed.
